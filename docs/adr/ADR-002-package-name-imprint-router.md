# ADR-002: Package name `imprint-router`

**Status:** Accepted · **Date:** 2026-08-26

## Context
`imprint` on npm is taken (0.0.0 placeholder). `imprint-ai` is taken (agent memory SDK). `myelin` is taken on PyPI.

## Decision
Product name stays **Imprint**; npm/PyPI package identity is **`imprint-router`** (verified available on both registries).

## Rationale
- Consistent with the ecosystem convention (`a3m-router`)
- Keeps the chosen brand while avoiding all conflicts
- Council minority preferred `knack-ai`; rejected as weaker tie to the A3M story
